# Ankit Kumar Chaudhary — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ankit-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, your site will be available at:
   `https://chaudhary97.github.io/ankit-portfolio/`

Use that published URL in the Hack2Skill **Portfolio Link** field.
